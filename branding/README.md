# Branding

`source/make_icon.py` draws the 32x32 pixel icon (the sort glyph) and writes `icon/`. `source/banners.html` holds every
banner; `source/render_banners.py` renders them to `banners/` with headless Chrome. Run both from the repository root.
Fields, gallery notes and the checklist are in [LISTING.md](LISTING.md).
